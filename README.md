# StyleWIZ

StyleWIZ is a mobile/web application designed to simplify daily styling decisions by serving as a digital wardrobe management system and intelligent outfit generator.

## Project Overview
The application allows users to catalog, categorize, and manage their personal clothing collection digitally. Beyond basic inventory tracking, users can manually compose and save custom outfits or utilize the Smart Recommendation System to generate optimal outfit suggestions based on specific occasions, personal preferences, and defined constraints.

## Tech Stack
* **Platform:** Native Android (Android Studio)
* **Language:** Java
* **Database & Backend Services:** Firebase Firestore, Firebase Authentication
* **API Architecture:** RESTful APIs (HTTP/JSON integration)

## Key Features
* **Digital Closet Management:** CRUD operations for uploading, updating, and categorizing personal clothing items.
* **Custom Outfit Builder:** Logical grouping of individual garments into complete saved outfits.
* **Smart Recommendation Engine:** Rule-based logic that queries user preferences and item attributes to deliver contextual outfit suggestions for different occasions.
* **Data Persistence & State:** Real-time synchronization between the client interface and backend database using JSON payloads.
